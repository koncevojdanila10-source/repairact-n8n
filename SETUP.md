# Настройка

## Требования

n8n с узлами Telegram Trigger 1.3, Telegram 1.2, Data Table 1.1, AI Agent 3.1, OpenAI audio 2.3, OpenAI Chat Model 1.3, Structured Output Parser 1.3, Google Docs 2, Google Drive 3, Set 3.4, Switch 3.4, IF 2.3 и Code 2. В старых установках отсутствующие версии потребуется обновить.

Используются существующие узлы n8n; установка сторонних community-узлов не нужна.

## Подключения

Создайте собственные credentials:
- **Telegram API** — токен отдельного бота, в узлах Telegram и Telegram Trigger.
- **OpenAI API** — распознавание аудио и модель извлечения фактов. В шаблоне модель `gpt-4.1-mini`; проверьте доступность и тариф в своём аккаунте.
- **Google Docs OAuth2** — создание и заполнение нового документа.
- **Google Drive OAuth2** — экспорт Google Docs в PDF.

Никакие токены не вводите в исходный код или GitHub. Выбирайте credentials в интерфейсе n8n. Для одного Telegram-бота не запускайте несколько независимых Telegram Trigger: настройте отдельного бота для этого workflow.

## Доступ и черновики

В «Настройки доступа» укажите разрешённые chat ID через запятую. Поддерживаются личные чаты; группа и неразрешённый пользователь не отправляются на распознавание.

Создайте таблицу по описанию `drafts-table.schema.json`. Системные `id`, `createdAt`, `updatedAt` n8n добавляет самостоятельно — отдельные пользовательские колонки с этими именами не создавайте.

Замените таблицу в узлах:
1. Очистить просроченные черновики
2. Сохранить черновик
3. Привязать кнопки к сообщению
4. Забрать черновик однократно
5. Сохранить ID документа
6. Завершить черновик

Черновик доступен 24 часа. После доставки или отказа его текст очищается. Просроченные ожидающие записи очищаются при следующем отчёте, не по отдельному расписанию. Незавершённая обработка сохраняется для восстановления.

## Проверка после импорта

- `/help` показывает пример, не создаёт акт.
- Полный текстовый отчёт даёт черновик.
- Тот же отчёт голосом даёт корректную расшифровку и черновик.
- «Создать PDF» не открывает сайт, доставляет один файл.
- «Исправить» отменяет текущий черновик; отправьте полный исправленный отчёт.
- Повторное нажатие старой кнопки не создаёт документ снова.
- Непонятная валюта или отсутствующее имя мастера вызывают уточнение.
- Неразрешённый пользователь не получает доступа к актам.

Локальные тесты не проверяют реальные OAuth-подключения, качество нового аудио, доступность API или доставку Telegram. Проверяйте их отдельно на вымышленном отчёте.

## Если PDF не пришёл

Проверьте соответствующее выполнение n8n и поле `documentId` в записи черновика. Если документ уже создан, восстановите заполнение/экспорт/доставку по этому ID, не создавайте второй документ. Автоматически возвращать запись `processing` в `pending` нельзя.
