# RepairAct — отчёт о ремонте → PDF

Telegram-бот на **n8n**: мастер отправляет голосовое сообщение, аудиофайл или текст; бот собирает черновик акта, мастер проверяет его, затем получает PDF в Telegram.

## Что умеет

- Распознаёт голосовые сообщения и поддерживаемые аудиофайлы.
- Разделяет мастера и заказчика, запчасти и стоимость работ.
- Показывает понятный пример по `/start`, `/help` и `/example`.
- Просит уточнить неоднозначные данные; валюту и неизвестные цены не угадывает.
- Кнопки «Создать PDF» и «Исправить» работают **внутри Telegram**, без открытия сайта.
- Создаёт отдельный Google-документ и отправляет его PDF-версию.
- Ограничивает доступ списком Telegram chat ID.
- Связывает черновик с чатом и сообщением; повторное нажатие обработанной кнопки не выпускает акт заново.

## Быстрый старт

1. Импортируйте [RepairAct.json](RepairAct.json) в свой n8n.
2. Создайте отдельного Telegram-бота и выберите свои credentials в узлах Telegram, OpenAI, Google Docs и Google Drive.
3. Создайте **пустую** Data Table `RepairAct_drafts` с колонками из [drafts-table.schema.json](drafts-table.schema.json). Это описание колонок, не файл для автоматического импорта строк.
4. Выберите созданную таблицу во всех **6** узлах Data Table вместо `REPLACE_WITH_DRAFTS_TABLE_ID`.
5. В узле «Настройки доступа» заполните `allowedChatIds` — разрешённые Telegram chat ID через запятую. В публичной копии список пуст: доступ закрыт по умолчанию.
6. Проверьте настройки и активируйте импортированный workflow. Отправьте боту `/help`, затем тестовый отчёт.

Подробности: [SETUP.md](SETUP.md). Пример: [repair-report.txt](repair-report.txt).

## Файлы

- `RepairAct.json` — актуальная очищенная версия workflow для импорта.
- `drafts-table.schema.json` — схема отдельного хранилища черновиков.
- `repair-report.txt` — вымышленный пример, одинаково подходит для голоса и текста.
- `smoke.test.cjs` — локальные проверки маршрутизации, расчётов и защиты черновика.

Для локальных тестов нужен Node.js; дополнительных пакетов не требуется:

```sh
node --test smoke.test.cjs
```

## Важно

Это публичный **шаблон**, а не подключение к рабочему боту автора. Токены, credentials, реальные chat ID, ID таблиц/документов, содержимое актов и история выполнений не публикуются. Исходная рабочая автоматизация не изменяется при импорте копии.

Текст и аудио передаются OpenAI; созданный акт сохраняется в Google Drive. Использование API может быть платным. Читайте [SECURITY.md](SECURITY.md) перед запуском.

Подтверждение черновика не является подписью заказчика, подтверждением оплаты или гарантии. Повторная отправка самого отчёта создаёт новый черновик — это отдельный случай от повторного нажатия кнопки.

Лицензия на распространение пока не выбрана.
